# Kimberly · The XV Issue (invitation experiment)

An editorial "fashion magazine" take on Kimberly's XV invitation (Saturday, August 29, 2026).
Built by REGO Agency as a design experiment; reuses the photos, videos and music from
[kimberly-xv-gracias](https://github.com/Rolz-Royz/kimberly-xv-gracias). Event details
come from the original Canva invitation.

- Magazine cover gate: tap it and the cover turns like a page
- Cover story video, editors' letter from her parents, clickable contents page
- Split-flap date with live countdown, sticky-clock program (Mass, dinner, waltz, party)
- Dress code swatch cards, zooming photoshoot grid, padrinos credits, gifts, RSVP
- English / Spanish toggle, background music (Zoé — "Luna" excerpt), photo viewer

Not indexed by search engines (see `robots.txt` and the `noindex` meta tag).

## Local preview

    node server.js     # http://localhost:4620

Add `?open` to the URL to skip the cover animation.
